LESSON 01 · HTML BASICS

Your First Webpage

HTML ka full form HyperText Markup Language hai. Isse browser ko batate hain ki page par heading, paragraph, image ya link kya hai. HTML programming language nahi, ek markup language hai.

index.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>Meri pehli website.</p>
</body>
</html>

Samjho: <head> mein page ki information, aur <body> mein screen par dikhne wala content hota hai.

Hello, World!

Meri pehli website.

LESSON 02 · HTML CONTENT

Headings & Paragraphs

Headings ke liye <h1> se <h6> tak tags hote hain. <h1> main heading ke liye hota hai. Paragraph ke liye <p> use karo.

Example
<h1>Vidya Nirman</h1>
<h2>Coding Academy</h2>
<p>Main web development seekh raha hoon.</p>

Vidya Nirman

Coding Academy

Main web development seekh raha hoon.

LESSON 03 · LINKS & IMAGES

Connect pages and show images

Link ke liye <a> tag aur image ke liye <img> tag use hota hai. href link ka destination hota hai; src image ka path.

Example
<a href="https://vidyanirman.online">
  Visit Vidya Nirman
</a>

<img src="logo.png" alt="Vidya Nirman logo" width="120">

Best practice: har meaningful image mein descriptive alt text rakho, taaki image load na hone par bhi uska context samajh aaye.

LESSON 04 · CSS BASICS

Style your webpage with CSS

CSS ka full form Cascading Style Sheets hai. HTML structure banata hai, CSS uska look control karta hai. Selector batata hai kis element ko style karna hai.

style.css
body {
  background-color: #fff9e6;
  font-family: Arial, sans-serif;
}

h1 {
  color: #8b1e2d;
  text-align: center;
}

p {
  font-size: 18px;
}

CSS rule mein selector (jaise h1), property (jaise color) aur value (jaise #8b1e2d) hoti hai.

LESSON 05 · CSS CARDS

Create a simple card

Cards information ko neat box mein dikhate hain. padding content ke andar space hai, margin element ke bahar space, aur border-radius corners ko round karta hai.

HTML + CSS
<div class="card">
  <h2>My First Card</h2>
  <p>Practice makes progress!</p>
</div>

/* CSS */
.card {
  background: white;
  color: #220308;
  padding: 20px;
  border-radius: 14px;
  border: 2px solid #d4af37;
}

My First Card

Practice makes progress!

LESSON 06 · JAVASCRIPT

Variables and values

JavaScript webpage mein logic aur actions add karta hai. Variable ek named container jaisa hai jisme value store kar sakte hain. Modern JS mein values ke liye aksar const ya let use hote hain.

script.js
const student = "Learner";
let lessonsCompleted = 1;

console.log("Hello, " + student);
console.log(lessonsCompleted);

const ko dobara assign nahi kar sakte; let ko update kar sakte hain. console.log() developer console mein output dikhata hai.

LESSON 07 · INTERACTIVITY

Make a button work

Event ka matlab user action, jaise click. addEventListener() kisi action par code chalata hai. Neeche button click karke dekho.

HTML + JavaScript
<button id="helloBtn">Click me</button>
<p id="message"></p>

<script>
document.getElementById("helloBtn")
  .addEventListener("click", function() {
    document.getElementById("message").textContent =
      "Great job! Button works.";
  });
</script>

LESSON 08 · RESPONSIVE DESIGN

Mobile-friendly website banao

Responsive design ka matlab page mobile, tablet aur computer par achchhe se fit ho. Viewport meta tag browser ko screen width ke hisaab se page render karne mein help karta hai. CSS media query screen ki width ke hisaab se style badal sakti hai.

Responsive CSS
.container {
  width: min(100% - 32px, 900px);
  margin-inline: auto;
}

.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

@media (max-width: 650px) {
  .cards { grid-template-columns: 1fr; }
}

Tip: page ko test karne ke liye browser window chhoti karo. Mobile layout mein horizontal scrolling avoid karo.

LESSON 09 · HTML FORMS

Forms aur user input

Forms se user naam, email ya message enter kar sakta hai. Har input ko label dena accessibility ke liye achchha hai. Ye demo sirf browser mein kaam karta hai; data kisi server par send nahi hota.

HTML form
<form>
  <label for="studentName">Your name</label>
  <input id="studentName" type="text" required>
  <button type="submit">Say hello</button>
</form>

LESSON 10 · JAVASCRIPT LOGIC

Functions aur if/else

Function reusable code ka block hai. if/else condition ke basis par decision leta hai.

script.js
function checkMarks(marks) {
  if (marks >= 33) {
    return "Pass";
  } else {
    return "Keep practising";
  }
}

console.log(checkMarks(78));

Real applications mein marks ya personal data ko validate karne ke liye sirf browser-side check par depend mat karo; server-side validation bhi zaroori ho sakti hai.
